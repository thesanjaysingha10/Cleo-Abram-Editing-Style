# Cleo Abram Editing Style

A Claude Code skill for editing videos in a Cleo Abram / "Huge If True" science-explainer style, built on Remotion.

- `SKILL.md` — the skill: playbook, motion table, placement and sound rules, idea bank
- `assets/remotion/cleo/` — the Remotion component library (copy to `src/cleo/`, then `npm i @remotion/google-fonts`)
- `assets/remotion/example/` — example compositions
- `references/` — style report, deep pass, scene data, motion references and prototypes

Install as a skill: copy this folder to `~/.claude/skills/cleo-abram/`.
